# 🤖 AI Automation & Infrastructure Studio

This repository showcases my technical environment for scaling AI content production and optimizing local hardware resources.

---

### 🛠 Tech Stack & Infrastructure
* **Hardware:** HP Omen (NVIDIA RTX 5060 GPU)
* **Connectivity:** Starlink (High-speed, low-latency deployment)
* **Environment:** Docker, Miniconda, Node.js
* **AI Tooling:** Ollama, ComfyUI, Coqui TTS, PyTorch (CUDA optimized)

---

### 🚀 Key Implementations

#### 1. GPU Cloud Integration (Salad)
* Managed local Docker containers to provide distributed GPU power via the **Salad** network.
* Optimized hardware thermal performance and power consumption during high-load monetization cycles.

#### 2. Automated Video Workflows
* Built end-to-end character consistency pipelines using **AnimateDiff** and **IP-Adapter**.
* Implemented Python-based voice cloning using **Coqui TTS** for automated narration.

#### 3. Local LLM Deployment
* Configured **Ollama** and **OpenClaw** for private, local script generation to eliminate API costs and maintain data privacy.

---
### 📂 Repository Structure
* `/scripts`: Python and Bash scripts for environment setup.
* `/docker`: Dockerfiles for containerized AI workflows.
* `/configs`: Optimized JSON configurations for ComfyUI.
